# Ollama Spring Boot Agent

This is a simple Spring Boot application that integrates with [Ollama](https://ollama.ai/) using Spring AI to serve local language models. 

By default, this project is configured to use the `qwen2.5:1.5b` model, which is highly efficient and capable for machines with 8GB RAM.

## Prerequisites

1. Install [Ollama](https://ollama.ai/download).
2. Pull and run the required model in your terminal:
   ```bash
   ollama run qwen2.5:1.5b
   ```

## Running the Application

In a separate terminal window, start the Spring Boot application from the project root:

```bash
./mvnw spring-boot:run
```

The server will start on port `8081`.

## API Endpoints

The application exposes two main endpoints via `ChatController`. **Both endpoints now support autonomous tool calling (e.g., checking the current time)**. 

### 1. Standard Chat (Blocking)
Waits for the model to generate the full response before returning it.

**Browser Test:**  
[http://localhost:8081/chat?message=What%20is%20the%20time%20right%20now?](http://localhost:8081/chat?message=What%20is%20the%20time%20right%20now?)

**cURL Tests:**
```bash
# Test Tools
curl "http://localhost:8081/chat?message=What+is+the+current+date+and+time"
```

### 2. Streaming Chat
Streams the words back to the client as they are generated by the model.

**Browser Test:**  
[http://localhost:8081/stream?message=Tell%20me%20a%20story](http://localhost:8081/stream?message=Tell%20me%20a%20story)

**cURL:**
```bash
curl "http://localhost:8081/stream?message=What+time+is+it"
```
